# Russian text cover example

Plan a cover that needs Cyrillic typography:

```bash
gpt-image2-agent "Telegram cover for a post about AI agents. Add exact Russian title: 'АГЕНТЫ БЕЗ ХАОСА'. Dark premium background, one clear focal object." \
  --image-model gpt-image-2.5-sunburst \
  --preset russian-text \
  --preset thumbnail \
  --aspect landscape \
  --quality xhigh \
  --dry-run \
  --review-markdown
```

Always visually review Cyrillic spelling before publishing the final image.
